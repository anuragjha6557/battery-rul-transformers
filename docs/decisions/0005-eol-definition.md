# ADR-0005: EOL labelling rule, thresholds, start points and anomaly flags

- **Status:** Accepted
- **Date:** 2026-11-15
- **Evidence:** `reports/data_quality.md` (generated by `scripts/make_data_quality_report.py`), merge `b0db219`

## Context
RUL labels depend on when a cell "reaches end of life", and the source paper never defined that. The Phase-2 data-quality report shows the choice is not cosmetic:
- **CALCE:** about 3 % of cycles have a skipped CV charge step, an equipment artifact that makes a one-cycle capacity dip of about 0.11–0.13 Ah. At 80 % SOH, the raw first crossing (cycles 69–311) and a robust crossing (499–607) differ by **188–538 cycles** in 4/4 cells. At 70 % they differ by 102–192 cycles.
- **NASA:** the rule does not change any 80 % label. At 70 %, three of four cells never sustain the crossing.

## Options considered
| Rule | 80 % EOL, CALCE | Problem |
|---|---|---|
| `raw`: first cycle < θ | 69–311 | A single artifact cycle defines "death". This is indefensible. |
| `rolling_median(5)`, centred | 499–600 | Robust. Its window is a free parameter. |
| `sustained(n=5)`: first of 5 consecutive cycles < θ | 499–607 | Robust and easy to explain. Within 7 cycles of the rolling median in all 16 (cell × θ) cases. |
| `masked` + `sustained`: drop flagged artifact cycles, then sustained | 499–607 | Identical to `sustained` on all 16 cases. Also robust to artifacts that cluster near the crossing. |

## Decision
1. **Labelling rule: `masked(base=sustained, n=5)`**, with the mask = `flag_skipped_cv | flag_partial_charge` from `battery_rul.data.quality`. Masked cycles are measurement artifacts, not degradation.
   - `long_rest` and `capacity_jump` are **not** masked. They are real electrochemical regeneration, and a forecaster must face them.
   - `no_paired_charge` is not masked either: its capacity measurement is valid.
   - *Counter-argument, accepted as true:* on these 8 cells the mask changes no label. It is kept because it costs nothing, it states the principle (labels describe degradation, not tester glitches), and it protects Toyota and user-uploaded data, where artifacts may sit near the crossing.
2. **A run cut off by the end of the record does not count** (censored). A crossing that the record cannot confirm for 5 cycles is not a confirmed EOL. This is conservative, and it makes NASA B0005 at 70 % censored where `raw` would say cycle 165.
3. **Thresholds:** θ = 0.80 is primary for all datasets; θ = 0.70 is a sensitivity analysis only. At 0.70, NASA B0005, B0007 and B0018 are censored, so NASA RUL at 0.70 rests on one cell, B0006, and is reported as anecdotal.
4. **Fixed-cycle prediction starts** (PROTOCOL §2), each below the dataset's earliest 80 % EOL:
   - **NASA: T_p ∈ {30, 50}**. The earliest EOL is B0006 at 61.
   - **CALCE: T_p ∈ {200, 400}**. The earliest EOL is CS2_36 at 499.
   - **Toyota: T_p = 100**. This is Severson's "first 100 cycles" setting, and every cleaned cell lives more than 100 cycles. The Toyota loader report confirms this before use.
5. **Fold independence:**
   - **NASA:** B0018 is the only rig-independent cell. B0005/06/07 rest schedules are identical to within 1 s on 166/166 cycles.
   - **CALCE:** all four cells count as independent. Shared long rests occur only at start-up cycles 2–4 and 54, and cross-cell ΔSOH correlation is ρ ∈ [−0.08, 0.12], against 0.55–0.69 for the NASA rig-mates.
6. **Flags as inputs:** flags of cycles ≤ T_p may be model inputs, since they are observable (e.g. "last cycle had a skipped CV"). A flag computed with a centred window uses future cycles, so feature code must recompute it causally. `partial_charge` and `capacity_jump` use centred medians in `quality.py` and **must not be used as inputs as-is**. The leakage test covers this.

## Consequences
- `battery_rul.tasks.rul` builds labels as `eol_masked(..., base=eol_sustained)` at θ ∈ {0.8, 0.7} and records the rule and θ in each run's MLflow params.
- `configs/task/*.yaml` take the fixed starts above. `splits.loco.independent_fold_cells("calce")` returns all four cells.
- **Interview point:** "The paper's CALCE RUL labels would move by up to 538 cycles depending on an undocumented smoothing choice, because of a tester artifact. We found it, flagged it, and made the rule explicit."

## Amendment 1 (2026-11-15, before any sweep): Toyota uses the provider's cycle life
**Finding.** With the Toyota tables loaded, the rule above censors **81/124** Toyota cells at θ = 0.80 and all 124 at θ = 0.70. Relaxing the end-of-record condition (a tail run of ≥ 2 cycles counts) does not help: still 81/124 at 0.80 and at Severson's own 0.88 Ah threshold.
- The cause is experimental design, not non-crossing. Severson's team stopped each test at about 80 % of *nominal* capacity (0.88 Ah). Our SOH reference is the first-5-cycle mean, 1.043–1.096 Ah, so 0.80 SOH ≈ 0.86 Ah, below where most records end. At 0.88 Ah the records end within a cycle or two of the crossing, often with noise, so no sustained run exists.
- Where the rule does resolve at 0.88 Ah, it reproduces the provider's `cycle_life` with **median difference 0 and max |difference| 2 cycles**.

**Decision.** Toyota EOL label = `cells.reported_cycle_life`: Severson's cycles to 0.88 Ah (80 % of nominal), after the official continuation merge. Consequences:
- No Toyota cell is censored, which matches the experimental design (every cleaned cell was cycled to EOL).
- Toyota results stay directly comparable with Severson 2019 and every later paper on this dataset.
- The θ = 0.70 sensitivity analysis does not apply to Toyota (the data stop near 80 %).
- NASA and CALCE keep the rule above. The label source is recorded per run (`label_source ∈ {rule, provider}`).

The trajectory-crossing RUL estimator (PROTOCOL §2, Task C) uses θ_cell = 0.88 Ah / C_ref,cell for Toyota, so that predicted crossings and labels share one definition.
